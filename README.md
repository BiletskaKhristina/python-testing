### Мета роботи

## Виконання роботи

### 1. Загальні принципи тестування та unittest

Було створено тестові випадки для перевірки правильності роботи функцій із використанням бібліотеки `unittest`.

Під час виконання завдання:

- ознайомилися з основними принципами тестування;
- створили тестовий файл `test_general.py`;
- перевірили результати виконання функцій;
- запустили тести та проаналізували результати.

**Результат:** 12 тестів пройшли успішно, також виконано 3 підперевірки.

### 2. Тестування за допомогою pytest

Було створено тести з використанням бібліотеки `pytest`.

Під час виконання завдання:

- створили файл `test_pytest.py`;
- використали можливості бібліотеки `pytest`;
- запустили тести через командний рядок;
- перевірили правильність роботи функцій.

**Результат:** усі 8 тестів пройшли успішно.

### 3. Аналіз покриття коду тестами

Для визначення рівня покриття коду використовували бібліотеки `coverage` та `pytest-cov`.

Виконані дії:

- налаштували параметри покриття коду;
- запустили тестування;
- сформували звіт про покриття;
- проаналізували отримані результати.

Команда для запуску:

```bash
poetry run pytest example/testing/03_coverage -v --cov=example/testing/03_coverage --cov-report=term-missing
```

**Результат:** 7 тестів пройшли успішно, покриття коду становило **100%**.

Було створено інтеграційні тести для перевірки взаємодії компонентів програми.

- запустили інтеграційні тести;
- проаналізували результати виконання.

**Результат:** усі 3 тести пройшли успішно.

## Висновок

Під час виконання роботи було створено та перевірено тести для програм мовою Python. Отримано практичні навички використання бібліотек `unittest` і `pytest`, проведення інтеграційного тестування та визначення покриття коду тестами.

Мету роботи досягнуто. Усі чотири набори тестів пройшли окрему перевірку. Під час виконання виникла складність з одночасним запуском тестів через конфлікт імпортів, однак вдалося успішно перевірити кожен набір окремо.
